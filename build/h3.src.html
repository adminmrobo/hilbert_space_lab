겹침 점수와 그림자는 실제로 어디서 일하고 있을까?

복도의 방 스무 개를 지나온 시아와 모아에게 박사가 출장 명단을 건넵니다. 신호실(소리를 물결 좌표로), 양자 측정실(그림자의 제곱이 확률), 보정실(그림자가 최선의 맞춤), 커널 작업실(닮음 점수로 휜 패턴 맞추기). 네 곳 모두 ①·②편의 도구 — 겹침 점수, 직각, 그림자 — 를 그대로 씁니다.

처음 오신 분께 — 이 페이지를 3줄로
  1. 무엇을: 힐베르트 공간이 쓰이는 네 현장을 실험 하나씩으로 봅니다.
  2. 왜 중요한가: 음성 필터, 양자컴퓨터, 센서 보정·회귀, 커널 머신러닝이 모두 "겹침 점수 + 그림자" 한 가지 계산입니다.
  3. 업무에서는: 진동 신호에서 고장 주파수 골라내기, 측정값 보정선 긋기, 데이터가 적을 때 휜 패턴 예측하기에 바로 씁니다.

코드·수식을 몰라도 됩니다. 앞 편의 방 번호를 함께 적어 두었습니다.

11신호실 — 소리를 물결 좌표로 원자료 PRACTICAL 1/4

방법: 물결 조각의 세기 = 좌표일상: 이퀄라이저로 고음만 줄이기원자료: PRACTICAL HILBERT SPACE 1/4 (@eeanimation)

왜 이 방법을 쓰나

  1. 문제: 소리·진동 신호에서 특정 높이의 성분만 빼거나 남기고 싶습니다(잡음 제거, 고장 진동 찾기).
  2. 앞 방법의 한계: 시간에 따른 그래프만 보면 어떤 높이의 소리가 얼마나 섞였는지 보이지 않아요.
  3. 해법: 서로 직각인 물결 조각(sin t, sin 3t …)과의 겹침 점수로 좌표를 구합니다. 필요 없는 조각의 좌표를 0으로 만들면 필터가 됩니다.
쉽게 말하면 곡선 하나가 "1번 물결 1만큼, 3번 물결 0.5만큼"이라는 막대 두 개가 됩니다(②편 8번 방).

수학 수식을 어려워하는 조수가 대신 물어봅니다

"3번 물결을 버리면 신호가 얼마나 망가지는지 숫자로 알 수 있어요?"

학교 수학으로 보면삼각함수의 정적분입니다. 0부터 2π까지 sin²(kt)의 넓이는 늘 π예요.
식 조각뜻
x(t) = sin t + 0.5 sin 3t신호 = 물결 두 조각의 합
⟨f, g⟩ = ∫₀²π f g dt겹침 점수 (곡선 방 L²[0, 2π])
남은 것 = 0.5 sin 3tsin t만 남기고 버린 조각
‖0.5 sin 3t‖² = 0.25 × π버린 세기 = 오차²
숫자로 한 번 해 보기
좌표: sin t 쪽 1, sin 3t 쪽 0.5 (겹침 점수 ÷ π)
sin t만 남기면 오차² = 0.25 × π = π/4 ≈ 0.785, 전체 세기 1.25π ≈ 3.93의 20%

버린 막대의 제곱만 더하면 잃은 양이 나오네요. 9번 방 피타고라스 그대로!

12양자 측정실 — 그림자의 제곱이 확률 원자료 PRACTICAL 2/4

방법: 확률 = 기준 상태와의 겹침 점수²일상: 비스듬히 선 막대의 두 그림자원자료: PRACTICAL HILBERT SPACE 2/4

왜 이 방법을 쓰나

  1. 문제: 큐비트는 재기 전에는 0과 1 사이에 "기울어진" 상태입니다. 재면 0이 나올지 1이 나올지 확률로 예측해야 해요.
  2. 앞 방의 한계: 지금까지 그림자는 "가장 가까운 점"을 찾는 데만 썼어요.
  3. 해법: 상태를 길이 1인 화살표로 놓고, 기준 상태 |0⟩·|1⟩ 위 그림자의 제곱을 확률로 씁니다. 길이 1이라 두 제곱의 합이 늘 1(피타고라스)이에요.
쉽게 말하면 길이 1인 막대를 60° 세우면 바닥 그림자 ½, 벽 그림자 √3/2. 제곱하면 ¼ + ¾ = 1 — 그대로 확률입니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

"왜 그림자를 그냥 쓰지 않고 제곱해요?"

학교 수학으로 보면삼각함수 cos² θ + sin² θ = 1입니다. 확률은 합이 1이어야 하니, 제곱한 값이 딱 맞아요.
식 조각뜻
|ψ⟩ = ½|0⟩ + (√3/2)|1⟩지금 상태 = 두 기준 상태의 섞임
⟨ψ|ψ⟩ = 1상태 화살표의 길이는 1
P(0) = |⟨0|ψ⟩|²0이 나올 확률 = |0⟩ 쪽 그림자²
P(1) = |⟨1|ψ⟩|²1이 나올 확률 = |1⟩ 쪽 그림자²
숫자로 한 번 해 보기
60° 기운 상태: 그림자 ½, √3/2 → P(0) = ¼ = 25%, P(1) = ¾ = 75%
1000번 재면 0이 대략 250번 (이 페이지의 시드 고정 모의 측정: 225번)

그림자 길이는 ½인데 확률은 ¼이구나. 제곱을 꼭 기억해야겠어요!

13보정실 — 최선의 맞춤은 그림자 원자료 PRACTICAL 3/4

방법: 측정값을 "설계표가 만들 수 있는 값들"에 그림자로일상: 세 번 잰 체중계 값을 하나로원자료: PRACTICAL HILBERT SPACE 3/4

왜 이 방법을 쓰나

  1. 문제: 센서 값이 매번 조금씩 다르게 나옵니다. 상수 하나 또는 직선 하나로 가장 잘 맞추고 싶어요.
  2. 앞 방의 한계: 정해진 모양(상수, 직선)으로는 모든 측정값을 정확히 지날 수 없을 때가 많아요.
  3. 해법: 측정값 b를 "설계표 A로 만들 수 있는 값들의 바닥"에 그림자로 내립니다. 그림자 b̂ = Ax̂가 최선의 맞춤이고, 빗나간 만큼 r은 바닥과 직각이에요.
쉽게 말하면 유클리드 6번 방의 "평균 = 그림자"를 측정 설계표로 넓힌 것입니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

"Aᵀ(b − Ax̂) = 0은 무슨 주문이에요?"

학교 수학으로 보면벡터의 내적이 0이면 수직. 이 식은 "빗나간 만큼이 설계표의 모든 열과 직각"이라는 뜻일 뿐이에요.
식 조각뜻
‖Ax − b‖² 를 가장 작게빗나간 거리의 제곱 합을 최소로
b̂ = Ax̂측정값의 그림자 = 맞춤값
Aᵀ(b − Ax̂) = 0빗나간 만큼은 설계표의 열과 모두 직각
A의 열 = (1, 1, 1)"상수 하나"로 맞출 때의 설계표
숫자로 한 번 해 보기
측정값 (2, 3, 4)를 상수 하나로 → c = 3, 빗나간 만큼 (−1, 0, 1), 합 0 (= (1, 1, 1)과 직각)
직선(x = 1, 2, 3)으로 맞추면 1 + 1·x → 2, 3, 4를 딱 지나 빗나간 만큼 0

빗나간 합이 0이 되는 게 우연이 아니었네요. 직각이라서!

14커널 작업실 — 닮음 점수로 휜 패턴 맞추기 원자료 PRACTICAL 4/4

방법: 커널 회귀 = 끝없는 방에서의 최소제곱일상: 가까운 동네 시세를 많이, 먼 동네는 조금 참고원자료: PRACTICAL HILBERT SPACE 4/4

왜 이 방법을 쓰나

  1. 문제: 데이터가 U자처럼 휘어 있습니다. 직선으로는 가운데와 양 끝을 동시에 못 맞춰요.
  2. 앞 방의 한계: 13번 방의 그림자는 설계표가 만드는 곧은 바닥에만 내릴 수 있었어요.
  3. 해법: 점을 끝없는 방으로 옮기면(φ) 그곳에서는 곧은 맞춤이 됩니다. 옮기는 계산 대신 닮음 점수 k(x, z) = ⟨φ(x), φ(z)⟩만 쓰면 돼요(②편 10번 방). 예측 = 이웃마다 (가중치 × 닮음 점수)의 합.
쉽게 말하면 새 지점의 값을, 가까운 데이터일수록 크게 참고해 섞어 만듭니다. 섞는 가중치는 그림자 계산으로 정해요.

수학 수식을 어려워하는 조수가 대신 물어봅니다

"σ랑 λ는 뭘 조절하는 손잡이예요?"

학교 수학으로 보면지수함수와 두 점 사이 거리, 그리고 연립방정식입니다.
식 조각뜻
k(x, z) = e−‖x − z‖²/(2σ²)가우스 닮음 점수: σ는 "얼마나 멀리까지 이웃으로 보나"
f(x) = Σ αᵢ k(xᵢ, x)예측 = 이웃마다 가중치 × 닮음
(K + λI) α = y가중치 구하기. λ는 너무 꼬불꼬불 외우지 않게 거는 제동
H = RKHS닮음 점수표로 만든 끝없는 방
숫자로 한 번 해 보기
거리 = σ → k = e−0.5 ≈ 0.607, 거리 = 2σ → e−2 ≈ 0.135
이 데이터(18개): 직선 맞춤 평균 오차² 1.78 → 커널(σ = 1, λ = 0.1) 0.07

σ가 너무 작으면 점마다 외우고, λ가 크면 둔해지는군요. 둘 다 적당히!
