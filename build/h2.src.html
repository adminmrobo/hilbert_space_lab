힐베르트 공간 ② — 곡선을 쪼개는 방

울퉁불퉁한 곡선 하나를, 몇 개의 숫자로 줄여 다시 만들 수 있을까?

①편에서 끝없는 방에도 자와 각도기가 있다는 걸 확인했어요. 이번엔 그 도구로 곡선을 쪼갭니다. 곡선을 자 세트로 읽고, 그림자로 가장 가까운 곡선을 찾고, 물결 조각(sin·cos)으로 나누고, 조각마다 세기를 재서 큰 조각만 남깁니다. 음성 인식과 MP3 압축이 하는 일이에요. 마지막엔 시아와 모아가 「곡선 맞히기」로 겨룹니다.

글 · 안상선 ((주)M-Robo 대표) · 저자 소개 · 2026-11-19 · v1.0

처음 오신 분께 — 이 페이지를 3줄로
  1. 무엇을: 곡선을 서로 직각인 물결 조각들의 합으로 나누고, 조각마다 "얼마나 들어 있나"를 잽니다.
  2. 왜 중요한가: 조각의 세기 합이 곡선 전체 세기와 같아서(피타고라스의 확장), 큰 조각만 남겨도 곡선을 거의 그대로 살릴 수 있습니다.
  3. 업무에서는: 센서 신호의 잡음 걸러 내기, 음성·진동 데이터를 몇 개의 숫자로 줄여 모델에 넣기에 씁니다.

코드·수식을 몰라도 됩니다. 식은 조수 하루가 숫자로 한 번씩 풀어 드립니다.

6곡선을 읽는 자 세트 원자료 카드 06

방법: 좌표 = 그 자와의 겹침 점수일상: 스무디를 과일별 컵 수로원자료: HILBERT SPACE 06/10 (@eeanimation)

왜 이 방법을 쓰나

  1. 문제: 곡선도 화살표처럼 좌표(숫자 목록)로 적고 싶습니다.
  2. 앞 방의 한계: 곡선 방에는 칸이 끝없이 많아, 가로·세로 같은 자가 따로 없어요.
  3. 해법: 길이 1이고 서로 직각인 곡선들을 자로 씁니다. 좌표 cₖ는 "곡선과 k번째 자의 겹침 점수" 한 번이면 나와요.
쉽게 말하면 스무디를 "사과 0.8컵, 딸기 0.5컵, 바나나 0.3컵…"으로 되돌리는 일. 컵 수가 좌표입니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

"자가 끝없이 많으면 좌표도 끝없이 많은 거죠? 그걸 언제 다 더해요?"

학교 수학으로 보면좌표와 내적, 그리고 급수입니다. 앞쪽 몇 개만 더해도 거의 다 맞으면, 나머지는 작아서 끝까지 더한 값에 수렴해요.
식 조각뜻
⟨eⱼ, eₖ⟩ = δⱼₖ자끼리: 같으면 1, 다르면 0 (직각)
cₖ = ⟨f, eₖ⟩k번째 좌표 = 겹침 점수
f = Σ cₖ eₖ좌표 × 자를 모두 더하면 원래 곡선
eₖ(t) = √2 sin(kπt)이 방에서 쓰는 자 (0 ≤ t ≤ 1)
숫자로 한 번 해 보기
f = 0.8e₁ + 0.5e₂ + 0.3e₃ + 0.18e₄ + 0.1e₅ → 겹침 점수로 되돌리면 0.8, 0.5, 0.3, 0.18, 0.1
길이² = 0.64 + 0.25 + 0.09 + 0.0324 + 0.01 = 1.0224

뒤로 갈수록 좌표가 작아지니까, 앞쪽 몇 개만 더해도 거의 같은 곡선이 되네요!

7그림자가 가장 가까운 답 — 끝없는 방에서도 원자료 카드 07

방법: 닫힌 바닥 위 수선의 발일상: 정오의 그림자원자료: HILBERT SPACE 07/10

왜 이 방법을 쓰나

  1. 문제: 쓸 수 있는 조각이 정해져 있을 때, 그 조각들로 만들 수 있는 곡선 중 원래 곡선에 가장 가까운 것을 찾고 싶습니다.
  2. 앞 방의 한계: 6번 방에서 조각을 몇 개만 켜면 원래 곡선과 어긋났어요. "어긋난 것 중 최선"인지는 몰랐죠.
  3. 해법: 그 조각들이 이루는 바닥 M에 똑바로 그림자를 내립니다. 빗나간 만큼 r은 바닥과 직각이고, 그림자 p보다 가까운 곳은 없어요.
쉽게 말하면 유클리드 6번 방의 그림자가 끝없는 방에서도 그대로 통합니다. 6번 방에서 앞 조각 몇 개만 켠 곡선이 바로 그 그림자예요.

수학 수식을 어려워하는 조수가 대신 물어봅니다

"끝없는 방에서도 그림자가 하나뿐이에요? 여러 개면 어떡해요?"

학교 수학으로 보면정사영과 점과 평면 사이의 거리입니다. 바닥이 "닫혀" 있으면(빈틈 없으면) 그림자는 딱 하나예요.
식 조각뜻
x = p + r원래 = 그림자 + 빗나간 만큼
p = PMx바닥 M에 떨어뜨린 그림자
r ⟂ M빗나간 만큼은 바닥과 직각
‖x − p‖ ≤ ‖x − m‖바닥 위 어떤 m보다 p가 가깝다
숫자로 한 번 해 보기
x = (2, 1, 3), 바닥 = x₁x₂ 평면 → p = (2, 1, 0), r = (0, 0, 3), 거리 3
바닥 위 다른 점 m = (1, 1, 0)까지는 √(1 + 0 + 9) ≈ 3.16 → 더 멂

빈틈 없는 방이라서 그림자가 꼭 하나 있구나. 4번 방이 여기서 쓰였네요!

8물결 조각으로 나누기 (푸리에) 원자료 카드 08

방법: sin·cos 조각의 합일상: 합창을 파트별로 듣기원자료: HILBERT SPACE 08/10

왜 이 방법을 쓰나

  1. 문제: 소리·진동처럼 출렁이는 곡선을 몇 개의 숫자로 줄이고 싶습니다.
  2. 앞 방의 한계: 그림자를 내릴 조각을 아무렇게나 고르면 조각이 많이 필요해요.
  3. 해법: 매끈한 물결(sin·cos)을 조각으로 씁니다. 물결 조각들은 서로 직각이라, 조각마다 겹침 점수 한 번으로 세기가 나와요.
쉽게 말하면 울퉁불퉁한 곡선도 매끈한 물결 여러 개를 더하면 만들어집니다. 조각을 늘릴수록 원래 곡선에 가까워져요.

9피타고라스 정리의 확장 (파스발) 원자료 카드 09

방법: 전체 길이² = 조각 길이²의 합일상: 용돈을 통장 여러 개에 나눠도 합은 같다원자료: HILBERT SPACE 09/10

왜 이 방법을 쓰나

  1. 문제: 조각을 몇 개까지 남겨야 곡선을 충분히 살리는지 알고 싶습니다.
  2. 앞 방의 한계: 조각을 늘릴수록 가까워진다는 건 알았지만, "얼마나" 살렸는지 숫자가 없었어요.
  3. 해법: 곡선의 세기(길이²) = 조각 세기(좌표²)의 합. 그래서 남긴 조각의 좌표²만 더하면 몇 %를 살렸는지 바로 압니다.
쉽게 말하면 가로 3, 세로 4인 화살표의 길이²는 9 + 16 = 25. 조각이 끝없이 많아도, 곡선이어도 똑같습니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

"곡선 넓이를 구하는 거랑 막대 제곱을 더하는 게 정말 같은 값이에요?"

학교 수학으로 보면피타고라스 정리입니다. 조각들이 서로 직각이라 "가로² + 세로²"가 끝없이 이어질 뿐이에요.
식 조각뜻
‖x‖² = ∫ x(t)² dt곡선의 세기 (제곱의 넓이)
Σ |⟨x, eₖ⟩|²조각 세기의 합
둘이 같다자 세트에 빠진 자가 없을 때 (완전한 자 세트)
숫자로 한 번 해 보기
x = 3e₁ + 4e₂ → 조각 세기 9 + 16 = 25, 곡선 제곱의 넓이도 25, 길이 5
첫 조각만 남기면 9 ÷ 25 = 36%, 두 조각 모두면 100%

그럼 큰 조각부터 남기면 적은 조각으로 많이 살리겠네요. 대결 힌트 발견!

용돈 25만 원을 통장 두 개에 9만 원·16만 원으로 나눠 넣어도 총액은 25만 원입니다. 통장(조각)이 몇 개든 합은 그대로예요.

왜 이 방법을 쓰나 (커널 방)

  1. 문제: 안쪽 원의 점(+)과 바깥 고리의 점(−)을 가르고 싶습니다.
  2. 앞 방의 한계: 유클리드 7번 방의 곧은 칸막이로는 원을 둘러싼 무리를 가를 수 없어요.
  3. 해법: 점마다 "다른 점들과의 닮음 점수표(커널)"를 붙여 끝없는 방으로 옮기면, 그곳에서는 곧은 칸막이로 갈립니다. 원래 방으로 돌아와 보면 그 칸막이가 휘어진 경계로 보여요.
쉽게 말하면 좌표를 몰라도 "누구와 누가 얼마나 닮았나" 표만 있으면 칸막이를 세울 수 있습니다.
