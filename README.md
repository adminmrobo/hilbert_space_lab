# hilbert_space_lab — 끝없는 방의 자와 각도기

연구실 해설 시리즈: 시아·모아가 연구실 복도의 "열 개의 방"을 통과하며 힐베르트 공간을 배웁니다.
유클리드 공간에서 출발해 길이·각도·그림자·물결 조각이 인공지능·머신러닝의 어떤 계산이 되는지 잇습니다.

- 먼저 보고 오면 좋은 시리즈: 좌표축 위의 그릇 (optimization_3d_map)
- 구성: 0편 오리엔테이션 → ①편 화살표의 방(입구 방 + 1~5) → ②편 곡선을 쪼개는 방(6~10 + 대결)
- 원자료: 인포그래픽 「HILBERT SPACE 01~10」(@eeanimation)
