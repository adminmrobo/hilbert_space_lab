## 1. 한 줄 콘셉트
화살표에 쓰던 **길이·각도·그림자**를, 끝없이 긴 목록과 곡선(함수)에도 쓸 수 있게 만든 방이 힐베르트 공간이다.
머신러닝이 하는 일 대부분(유사도 재기, 오차 줄이기, 신호 쪼개기)이 이 방의 규칙 위에서 돌아간다.

## 2. 처음 오신 분께 — 3줄 상자 (초안)
- **무엇을**: 데이터를 화살표로 보고, 그 길이·각도·그림자를 재는 방법을 배웁니다.
- **왜 중요한가**: 추천, 검색, 회귀, 음성 인식이 모두 "두 화살표가 얼마나 닮았나", "가장 가까운 점은 어디인가"를 계산합니다.
- **업무에서는**: 비슷한 고객 찾기, 예측 오차 줄이기, 센서 신호 정리에 그대로 쓰입니다.
- 코드·수식을 몰라도 됩니다. (접는 상자: ℓ², L², RKHS, PCA, MSE 풀이)

- 인턴1·인턴2가 방을 하나씩 통과한다. 방을 나가려면 그 방의 실험 패널(원자료 차트)을 직접 움직여 답을 맞혀야 한다.
- 역할

  - 인턴2 모아(명부 No.006): 꼼꼼파. "그럼 끝이 없으면요?" 조건과 예외를 묻는다.

## 5. 방별 구성 (원자료 차트는 그대로 다시 그려 실험 패널로)
원자료 차트의 구도·색·기호는 그대로 SVG로 다시 그리고, 손으로 움직일 수 있게만 바꾼다. 출처 @eeanimation은 바닥글과 각 방 꼬리표에 밝힌다.

| 방 | 살리는 차트 | 실험 패널 (움직이는 것) | 일상으로 치면 | 숫자로 한 번 해 보기 (조수) | 학교 수학 |
|---|---|---|---|---|---|
| 1 | 세 겹 상자 + u+v 평행사변형 + θ + 점열 | u, v 끌기 → u+v 자동 | 장바구니 두 개 합치기 | u=(1,2), v=(3,1) → u+v=(4,3) | 벡터의 덧셈 |
| 2 | 화살표 x·y와 θ / f·g 곡선 겹침 | θ 슬라이더 → 내적 값 / 곡선 높이 조절 → 겹친 넓이 | 두 사람 취향표 비교 | x=(3,4), y=(4,3) → 24, cos θ = 24/25 = 0.96 | 내적, 코사인 |
| 3 | 노름·거리·직교 세 그림 | x, y 끌기 → 길이·거리·90° 알림 | 지도에서 직선거리 | (3,4)와 (−4,3) 내적 0, 거리²=25+25 | 피타고라스 |
| 4 | 점열 x₁→x 물방울 그림 | "구멍 뚫린 방" 켜기/끄기 | 1.4, 1.41, 1.414… 목적지 √2 | 유리수 방엔 √2가 없다 | 수열의 극한 |
| 5 | ℝⁿ 열벡터 / 1/k 막대 / |f|² 넓이 | k 늘리기 → 제곱합 누적 | 끝없이 줄어드는 할인 쿠폰 | Σ1/k² → 1.6449(π²/6) | 급수 |
| 6 | e₁⊥e₂ / 계수 막대 0.8·0.5·0.3… | 기저 회전 → 계수 변화 | 동서·남북으로 길 안내 | x=(3,4) → c₁=3, c₂=4 | 좌표 |

### 7·8·9번 방 쉬운 풀이 (본문 문장 기준)
- **7번 방 — 그림자 찾기**
  - 바닥(모델이 낼 수 있는 답들) 위에서 공중의 점(정답)에 가장 가까운 곳은, 점에서 바닥으로 똑바로 내린 발밑입니다.
  - 비스듬히 내리면 빗변이 되어 늘 더 깁니다(피타고라스).
  - 머신러닝의 예측선 긋기도 같습니다. 모든 점을 지나는 직선은 없으니, 빗나간 거리의 제곱 합이 가장 작은 직선을 고릅니다. 그 직선이 정답의 그림자입니다.
  - 가장 쉬운 예: 여러 번 잰 키를 숫자 하나로 대표하면 평균이 됩니다. 평균이 바로 그림자입니다.
  - 원어(Projection, Least Squares)는 접는 약어 상자에만 둡니다.
- **8번 방 — 물결 조각으로 나누기**
  - 울퉁불퉁한 곡선도 매끈한 물결(sin·cos) 여러 개를 더하면 만들 수 있습니다.
  - 각 물결이 "얼마나 들어 있나"는 2번 방의 겹침 점수로 잽니다.
  - 조각을 1개 → 3개 → 5개로 늘릴수록 원래 곡선에 가까워집니다(원자료 3번째 그림).
  - AI에서는: 음성 인식은 소리를 낮은 소리·높은 소리 조각의 세기로 바꿔서 봅니다. 음악 앱의 이퀄라이저 막대와 같은 그림입니다.
  - 주의 한 줄: "전체로는 가까워지지만, 꺾인 점 한두 곳은 끝까지 어긋날 수 있습니다."
- **9번 방 — 피타고라스 정리의 확장**
  - 가로 3, 세로 4인 화살표의 길이는 5입니다. 3²+4²=5²이죠.
  - 방향이 몇 개로 늘어나도, 곡선이어도 똑같습니다. 전체 길이의 제곱 = 조각 길이 제곱의 합.
  - 쓸모: 어느 조각이 전체의 몇 %를 차지하는지 바로 압니다. 큰 조각 몇 개가 90%를 넘으면 나머지는 버려도 됩니다.
  - AI에서는: MP3 압축, 데이터 특성 줄이기(PCA)가 이 계산으로 "얼마나 버려도 되는지"를 정합니다.

## 4-0. 입구 방 — 유클리드 공간 (v1.3 추가, v1.4 축소)

> **v1.4 (2026-11-19)**: 유클리드 공간이 같은 저장소의 앞 편(e0·e1·e2)으로 따로 만들어졌다. 그래서 힐베르트 쪽 입구 방은 "앞 편 요약 3줄 + 유클리드 콘텐츠 링크"로 줄이고, 칸 수 슬라이더(2 → … → 끝없이) 실험은 유클리드 ②편 끝 「복도 끝의 끝없는 방」에만 둔다(같은 실험이 두 번 나오지 않게). 0편 오리엔테이션도 유클리드 0편과 겹치지 않게, 힐베르트 0편은 "유클리드 편 + 그릇 시리즈 복습"으로 다시 짠다.

| ① 무엇인가 | 자(길이)와 각도기(각도)가 있는 평범한 방. 좌표평면(2칸)·공간좌표(3칸)를 n칸까지 늘린 것 | 키·몸무게 2칸, 키·몸무게·나이 3칸 |
| ② 왜 쓰나 | 데이터를 점으로 놓으면 "얼마나 먼가·얼마나 닮았나"를 숫자 하나로 잴 수 있다 | 시아(160, 50)와 모아(163, 54) 거리 = √(9+16) = 5 |
| ③ AI에서는 | 비슷한 고객 찾기(KNN), 예측선 긋기(회귀), 단어를 점으로 놓기(임베딩)가 모두 이 방에서 일어난다 | 추천 앱의 "비슷한 사람이 본 상품" |
| ④ 한계 | 칸 수가 정해져 있어야 한다. 소리·센서 곡선처럼 값이 끝없이 이어지는 데이터는 못 담는다 | 1초짜리 소리 = 숫자 4만 4천 개, 곡선 자체는 끝이 없음 |
| ⑤ 다리 | 그래서 자·각도기는 그대로 두고 방을 끝없이 넓힌 것이 힐베르트 공간 → 1번 방으로 | — |

- 실험 패널: 칸 수 슬라이더 2 → 3 → 10 → 100 → "끝없이". 끝없이를 누르면 칸이 곡선으로 바뀌며 1번 방 문이 열린다.
- 학교 수학: 좌표평면, 공간좌표, 두 점 사이의 거리.
- 조수 수식 상자: 거리 = √((가로 차)² + (세로 차)²)를 칸이 늘 때마다 항을 하나씩 더하는 모습으로.
- 0편과의 관계: 0편 「화살표」 카드는 그릇 시리즈 복습만, 입구 방은 새 개념(왜 이 방을 쓰나)만 다뤄 겹치지 않게 한다.

## 4-1. 용어 눈높이 규칙 (고등학교 수학 용어까지만)
본문에는 왼쪽 대신 오른쪽 말을 씁니다. 원어는 접는 약어 상자에만 둡니다. (페이지 문장에 "고등학생 눈높이" 같은 말은 쓰지 않습니다.)

| 원자료 용어 | 본문에서 쓰는 말 |
|---|---|
| 내적(inner product) | 겹침 점수 — 같은 자리끼리 곱해서 더한 값 |
| 노름(norm) | 길이 |
| 직교(orthogonal) | 직각 — 서로 영향을 주지 않는 방향 |
| 코시 수열 | 점점 서로 가까워지는 수열 |
| 완비성(completeness) | 빈틈 없음 — 다가가는 목적지가 방 안에 있다 |
| 정규직교기저 | 길이 1이고 서로 직각인 자 세트 |
| 계수 c_k | 그 조각이 들어 있는 양 |
| 사영(projection) | 그림자(정사영), 수선의 발 |
| 잔차 | 빗나간 만큼(남은 오차) |
| 최소제곱 회귀 | 빗나간 거리의 제곱 합이 가장 작은 직선 긋기 |
| 푸리에 급수 | 물결 조각으로 나누기 |
| 파스발 항등식 | 조각으로 나눠도 길이²의 합은 그대로(피타고라스 확장) |
| ℝⁿ / ℓ² / L² | 숫자 n개짜리 방 / 끝없는 목록 방 / 곡선 방 |
| 거의 모든 곳에서 같음 | 점 몇 개만 다르면 같은 것으로 본다 |
| 평균제곱 수렴 | 전체로 보면 가까워진다(점 하나하나는 아닐 수 있음) |
| RKHS·커널 | 닮음 점수표(커널)로 만든 방 — 10번 방에서 이름만 소개 |
| 10 | 4분할 그림 | 분할 클릭 → 해당 방으로 되돌아가기 | — | RKHS 점수 f(x)=Σα_i k(x,x_i) 예시 2점 | — |

방마다: 왜 이 방법을 쓰나 | 조수 수식 상자 → 칸 대화 2~3줄 → 실험 패널 → 풀이 → 이 방의 한계 → 확인 퀴즈 1문항.
