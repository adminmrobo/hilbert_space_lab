## 보완과제 Top 5
1. **AI 판단 코너 1개씩 (P6)** — 페이지마다 "AI가 이런 결과를 냈다. 이상한 곳은?" 상자.
   - ①: 길이 0.707인 두 곡선의 겹침 점수를 AI가 3.2라고 함 → 겹침 점수는 길이 × 길이(0.5)를 넘을 수 없다.
   - ②: AI가 조각 세기 합 1.3, 곡선 세기 1.0이라고 함 → 조각 세기 합은 전체 세기를 넘을 수 없다(9번 방).
   - ③: 상수항이 있는 회귀인데 AI 결과의 빗나간 값 합이 0.8 → 상수항이 있으면 합이 0이어야 한다(13번 방).
2. **기호 읽는 법 (P3)** — 기호 풀이 상자에 Σ(시그마: 모두 더하기), ∞(무한대: 끝없이), e(약 2.718), δⱼₖ(델타), Aᵀ(에이 트랜스포즈: 표를 눕힌 것), |ψ⟩(켓 프사이: 상태 화살표)를 추가.
3. **그림 먼저 (P1)** — 「왜」 상자 끝에 "식이 낯설면 아래 실험부터 눌러 보세요 ↓" 한 줄과 실험 패널 바로가기.
4. **해석 문장 연습 (해석 막힘형)** — 방마다 퀴즈 1문항에 "이 숫자가 바뀌면 결론은?" 문항 하나 추가(예: 12번 θ를 0°로 → P(0) = 100%).
5. **자기 점검 문장 (P6 보강)** — ③ 14번 끝에 "배운 데이터 오차만 보고 좋은 모델이라고 하지 않기" 체크리스트 3줄.

## 문제 문장 → 고친 문장
| 위치 | 지금 | 고친 안 |
|---|---|---|
| ① 5번 조수 표 | Σ |xₖ|² < ∞ | Σ |xₖ|² < ∞ — 목록의 숫자를 모두 제곱해 더한 값(Σ, "시그마" = 모두 더하기)이 끝없이 커지지 않는다(< ∞) |
| ② 6번 조수 표 | ⟨eⱼ, eₖ⟩ = δⱼₖ | ⟨eⱼ, eₖ⟩ = δⱼₖ — δⱼₖ("델타 제이케이")는 j와 k가 같으면 1, 다르면 0 |
| ② 10번 조수 표 | k(x, x′) = e^(−거리²/(2σ²)) | 닮음 점수 = e(약 2.718)의 "−거리² ÷ (2σ²)" 제곱. 거리 0이면 1, 멀수록 0에 가까워짐 |
| ③ 13번 조수 표 | Aᵀ(b − Ax̂) = 0 | Aᵀ("에이 트랜스포즈", 표를 옆으로 눕힌 것)(b − Ax̂) = 0 — 빗나간 만큼과 설계표의 각 열의 겹침 점수가 모두 0 |
| ③ 12번 조수 표 | P(0) = |⟨0|ψ⟩|² | P(0) = |⟨0|ψ⟩|² — ⟨0|ψ⟩("브라 0 켓 프사이")는 지금 상태와 |0⟩의 겹침 점수, 그것을 제곱 |

## 범위 밖이지만 알릴 것
- 캐릭터 팩(CHAR_lab4)의 성격은 시아 = 조용·꼼꼼, 모아 = 상냥·응원인데, 이 시리즈는 시아 = 직관파, 모아 = 꼼꼼파로 썼음. 캐릭터 설정이라 이 스킬로는 고치지 않음.
